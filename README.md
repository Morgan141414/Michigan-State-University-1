# Michigan State University Projects

## Solar System Simulation

The Unity project for the Solar System assignment is in [`GD MSU/GD Ex`](GD%20MSU/GD%20Ex/).

### Run in Unity

1. Install Unity Editor `2022.3.22f1` or a compatible newer version, including the platform build modules you need.
2. In Unity Hub, choose **Add** and select the `GD MSU/GD Ex` folder.
3. Open the project and wait for Unity to finish importing assets and compiling scripts.
4. Select **Tools > Solar System > Build Demo Scene** to generate the scene and supporting assets.
5. Open `Assets/Scenes/SolarSystem.unity` and press **Play**.

Click a planet to make the main camera follow it. The scene includes orbiting planets, a top-down minimap, comet spawning, materials, lighting, and generated ambient audio.

See the [project README](GD%20MSU/GD%20Ex/README.md) for build and submission notes.
