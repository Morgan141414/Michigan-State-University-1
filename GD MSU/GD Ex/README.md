# Solar System Simulation

Unity source project prepared from the grading criteria supplied with the assignment. The separate "Solar System Assignment" instruction sheet was not present in the workspace.

## Generate the scene

Open this folder in Unity 2022.3 LTS or newer. After the project finishes importing, select **Tools > Solar System > Build Demo Scene**. The editor tool creates the materials, procedural planet textures, minimap render texture, organized scene, and build-scene entry. Save the generated scene if prompted.

Open `Assets/Scenes/SolarSystem.unity` and press Play. Click a planet to have the main camera follow it. The map in the upper-right shows the system from above; comets spawn and travel through the scene.

## Build and publish

Use **File > Build Settings** to build for WebGL, Windows, and macOS (at least two platforms are required by the rubric). Install the corresponding Unity Build Support modules first. Upload each build to an itch.io project page and submit that page URL. Builds and an itch.io page cannot be produced from this workspace because Unity Editor and itch.io publishing access are not available here.
